# 冷食キーパー (Frozen Keeper)

冷凍庫の中身を管理するためのアプリです。(単一HTMLファイル)
「何がどこにあるか分からない」「開けている時間を短くしたい」を解決するために作りました。

🔗 **アプリを開く**: https://mamichan2026.github.io/Frozen-Keeper/

## 主な機能

- **場所別に表示**：冷凍庫の仕切りや引き出しごとにアイテムをグループ表示。場所は自由に追加・名前変更・削除できます
- **検索・絞り込み**：名前で検索、レンチンだけで食べられるものだけを絞り込み表示
- **残量の管理方法を選べる**：
  - 個数で管理（1個、2個…とタップで増減）
  - 残量(%)で管理（約100%／75%／50%／25%をワンタップで切り替え。個数で数えにくいもの向け）
- **coop注文履歴の貼り付け登録**：coopの注文履歴ページからコピーしたテキストをそのまま貼り付けると、「冷凍」と表示されている商品だけを自動で抽出し、商品名・価格をまとめて登録できます。「◯個入り」のような表記から個数も自動検出（検出できなかったものは残量管理・100%として登録）
- **購入日／賞味期限、切り替え可能**：設定から「購入日で管理」「賞味期限で管理」を選択でき、表示や警告の出し方が変わります
- **使用履歴**：使い切ったアイテムは履歴に残り、「また買いたい」「もう買わない」を記録できるので、次の注文時に参考になります

## 使い方

1. まず歯車マークから日付の管理方法と保管場所の名前設定してください
2. 右下の「＋」ボタンからアイテムを追加、または右上のクリップボードアイコンからcoopの注文履歴を貼り付けて一括登録
3. 場所チップやレンチン絞り込みで見たいものを表示
4. 使ったら「使い切った」、減ったら個数や残量%をタップして更新

## データについて

- データは**お使いのブラウザ内**に保存されます（localStorage）。他の人がこのサイトを使っても、データが共有されたり見えたりすることはありません
- サーバーには何も送信されません。ネット接続が必要なのはフォントの読み込みのみです

## 動作環境

- スマホ・PCの主要なブラウザで動作します
  スマホとPCで同一データを移行したい場合は、⚙️設定 → 一番下の『バックアップの作成・復元』から、コピー&貼り付けて移行できます(データを一度共通の場所に貼り付けておいてください)
- ビルドや特別なインストールは不要な、単一のHTMLファイルです
